생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 07 — 기획 최창섭.

**바로 쓰기: https://aebonlee.github.io/build-2611-07/** (물품설명서) · **대시보드: https://aebonlee.github.io/build-2611-07/dashboard.html** · **화물 추적: https://aebonlee.github.io/build-2611-07/tracking.html** · 자료 목록: https://aebonlee.github.io/build-2611-07/library.html

부품 정보를 입력하거나 엑셀로 여러 건 올리면 품목분류 질의용 물품설명서를 기획자가 보낸 양식 6절
(1 품명 머리글 · 2 구조 및 형태 · 3 기능 및 용도 · 4 성분(함량) 및 제조공정 · 5 제출서류 목록 · 6 품목분류 의견)로 만들고, 필수 항목 누락을 짚습니다.
HS 코드는 후보로만 적고 관세율 수치는 싣지 않습니다. 최종 판단은 담당자가 합니다.
AI(OpenAI·Anthropic)는 선택 사항이며, 키가 없어도 규칙 초안이 만들어집니다.
파일은 브라우저 안에서만 처리하며 서버로 올라가지 않습니다.

## v1.3 (2026-11-04) — 오류점수 분석

`errors.html`: 유니패스 귀책사유자별 오류현황 · 상세목록 엑셀을 올리면 신고번호로 인천 · 울산을 나눠 월별 표, 분기 경계, 담당자 표 대조, 항목별 원인, 관리대장, 공유 메일 초안을 만듭니다.

## 수출입통관 업무 대시보드 (v1.1)

ERP·환급프로그램·관세청에서 내려받은 엑셀을 올리면 수출입 통관 실적(본부·국가·업체·HS 4단위, 수입 관세부담율, 수출 전년 동기 대비), FTA 활용률·절감액, 본부별 월별 관세환급, 수출입 오류점수를 탭 4개에 모읍니다.
열 이름이 달라도 같은 뜻 낱말로 찾고, 못 찾은 필수 열은 화면에서 고릅니다. 매일 다시 올리면 갱신되고, 올린 날짜와 데이터 기간을 함께 보입니다. 탭별 집계는 엑셀로 내보냅니다.
## v1.2 (2026-11-04) — 양식 6절 · 품목분류 결정문 · 수입보세화물 추적

- 물품설명서: 기획자가 보낸 양식의 6절 이름·순서. 제출서류 목록·공급자 HS·상표 칸.
- 대시보드: 맨 위 「업무 7항목」 표(기획자 총괄 시트), 「품목분류 결정문」 탭 — 결정 건수·관세율 0% 결정 비율·종전보다 낮아진 건·절감 추정(종전세율·연간 수입액이 있을 때), 완제품·관세사·HS 4단위별, 월별, 세율별 분포, 목록.
- 화물 추적(`tracking.html`): BL 등록 → ERP 엑셀 / 유니패스 XML / OpenAPI(키 있을 때) 로 단계 가져오기 → 입항보고 제출·수입신고가 새로 생긴 건의 메일 초안(관세사·요청자) → 메일 앱으로 열기·복사·통보 기록. 퇴근 후·주말은 「시간 외」. **메일은 보내지 않고, 관세청 서버는 「조회」를 눌렀을 때만 부릅니다.**

```sh
node test/logic.test.js                 # 판정 339 (v1.0 91 + v1.1 132 + v1.2 116)
node test/smoke.browser.js              # 화면 119 (v1.0 23 + v1.1 54 + v1.2 42), playwright 필요
node tools/make-samples.mjs             # samples/ 예제 엑셀 5종 다시 만들기
```

예제 엑셀(가짜 본부·업체, 2024-01~2025-10)은 실제 사내 데이터가 아닙니다.
