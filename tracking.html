수입보세화물 Tracking

BL 번호를 등록해 두고 ERP 수입화물 진행현황 엑셀이나 유니패스 조회 결과를 넣으면, 「입항보고 제출」「수입신고」처럼 알려야 할 단계가 새로 생긴 건만 골라 관세사·요청자에게 보낼 메일 초안을 만듭니다. 퇴근 후·주말 처리 건은 「시간 외」로 표시합니다. 메일은 보내지 않고, 초안을 메일 앱으로 넘깁니다.

1. 추적할 BL 을 등록하세요

통관 요청이 들어온 BL 번호와 알릴 사람(관세사·요청자)을 적습니다. 목록은 이 브라우저에만 저장됩니다.

2. 진행 단계를 가져오세요

세 가지 중 편한 방법으로 넣습니다. 같은 BL · 같은 단계 · 같은 처리일시는 두 번 들어가지 않으니 하루에 몇 번이든 다시 넣어도 됩니다.

(a) ERP 「수입화물 진행현황」 엑셀 올리기

(b) 유니패스 OpenAPI 조회 결과(XML) 붙여 넣기

관세청 유니패스 「수입화물 진행정보」 OpenAPI 응답을 그대로 붙여 넣습니다. 태그 이름이 달라도 처리일시·처리구분·장치장을 찾아 읽습니다.

(c) OpenAPI 로 직접 조회 (인증키가 있을 때)

유니패스에 등록한 인증키를 넣고 「조회」를 누르면 그때만 관세청 서버를 부릅니다. 키는 이 브라우저에만 저장되고 어디로도 보내지 않습니다. 브라우저가 다른 사이트의 요청을 막으면(CORS) 조회 주소를 새 탭에 열어 나온 XML 을 (b) 에 붙여 넣으면 됩니다.

3. 현황

4. 알림 — 메일 초안

아래 단계가 새로 생긴 건마다 초안을 만듭니다. 제목·본문을 고친 뒤 「메일 앱으로 열기」를 누르면 메일 앱에서 보내기를 누르는 것은 사람입니다. 보낸 뒤 「통보함으로 표시」를 누르면 같은 건을 다시 알리지 않습니다.

밖이면 「시간 외」
메일 틀 바꾸기

이번 판에서 하지 않는 것

  • 메일 자동 발송 — 초안을 만들고 메일 앱으로 넘기기까지입니다. 보내는 것은 사람이 합니다.
  • 유니패스 자동 감시 — 정해진 시각마다 스스로 조회하지 않습니다. 사람이 엑셀을 올리거나 「조회」를 누를 때 읽습니다. 자동 감시는 사내 서버(배치)에서 할 일입니다.
  • 공휴일 판정 — 「시간 외」는 근무 시간 밖과 토·일만 봅니다.
  • 카카오톡 발송 — 한 줄 문구를 복사해 붙여 넣는 방식입니다.
